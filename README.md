# Writing Log

Nicole J Kimzey's writing tracker: daily word counts, writing and editing sessions, sprints with an alarm, streaks (Sundays are rest days), and a progress bar for each book.

- Runs on GitHub Pages: https://authornjk.github.io/writing-log/
- Reads word counts from Google Docs and keeps the log in one file in your Google Drive, "Writing Log data.json". Nothing about your writing is stored in this repository.
- `config.js` holds the Google sign-in client ID.
- `apps-script/Code.gs` is the optional nightly count that runs in your Google account.
